# Park Check 0.2

Denna version använder telefonens kamera genom bildfält med `capture="environment"`, hämtar användarens position efter tillstånd och har en riktig lokal nedräkning.

## Uppdatera GitHub

Ersätt filerna i ditt befintliga GitHub-projekt med innehållet i denna mapp. När ändringen sparas bygger Vercel automatiskt en ny version.

## Begränsning

Bilderna stannar i webbläsaren och skickas inte till någon analys. Resultatet är därför fortfarande exempeldata.
