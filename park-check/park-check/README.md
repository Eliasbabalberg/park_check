# Park Check

En klickbar prototyp som visar ett möjligt flöde för att kontrollera en parkering.

## Starta lokalt

1. Installera Node.js.
2. Öppna projektmappen i en terminal.
3. Kör `npm install`.
4. Kör `npm run dev`.
5. Öppna adressen som visas i terminalen.

## Publicera

Ladda upp hela innehållet i denna mapp till ett GitHub-projekt. Importera sedan projektet i Vercel och välj Deploy.

## Viktigt

Detta är en demonstration. Kamera, karta, plats, skyltanalys, priser och parkeringsregler är inte kopplade till riktiga tjänster.
